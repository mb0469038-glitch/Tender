# Iconography Rules & Guidelines

## Primary Standard: Lucide Icons (`lucide-react`)
Whenever UI components, screens, or buttons require icons, default to **Lucide Icons**.

### Visual Aesthetic
* Modern, minimal, clean, technical, and architectural.
* Consistent crisp outline stroke:
  * Default actions: `strokeWidth={1.8}` with `size={20}` or `size={22}`.
  * Inline badges / table helpers: `size={16}`.
* Color: Inherit current text color or use primary navy (`#0B1F4D`) / AMA blue (`#165BAA`).

### Standard AMA Domain Mappings
* **`<Building2 />`**: Projects, developments, structures
* **`<Layers3 />`**: Façades, building envelope systems, cladding
* **`<Ruler />`**: Architectural engineering, measurements, takeoffs
* **`<Factory />`**: Industrial manufacturing, fabrication
* **`<Wrench />`**: On-site installation, maintenance, field tools
* **`<ShieldCheck />`**: QA, certifications, compliance
* **`<FileText />`**: Tenders, BOQs, specifications, estimates
* **`<Users />`**: Team, contractors, project managers
* **`<MapPin />`**: Locations, site addresses
* **`<Phone />` / `<Mail />`**: Client contacts, inquiries

### Hierarchy & Alternatives
1. **Lucide Icons (`lucide-react`)**: Top recommendation for public AMA website & standard UI.
2. **Tabler Icons**: Approved alternative for deep internal ERP / heavy data grids.
3. **Avoid**: Heavy, filled, or cartoonish icon sets (e.g. Font Awesome Solid) that disrupt architectural minimalism.
